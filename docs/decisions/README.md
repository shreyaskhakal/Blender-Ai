## ADR Guidelines
Each ADR follows the standard format:
1. **Title & Metadata:** ID, title, status, date, author.
2. **Context:** Background and problem statement.
3. **Decision Drivers:** Core business, technical, and operational forces.
4. **Considered Alternatives:** Alternative solutions evaluated.
5. **Decision:** The chosen path and architecture.
6. **Consequences:** Positive and negative trade-offs.
7. **Risks & Mitigation:** Operational and technical risks.
8. **Revisit Triggers:** Conditions under which this decision should be re-evaluated.
